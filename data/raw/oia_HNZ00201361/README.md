Each workbook has one sheet (`ESPI1`, `ESPI2`, ...) with eight columns:
`REGION_NAME, DHB_NAME, SPECIALTY_NAME, MONTH_YEAR, NUMERATOR, DENOMINATOR,
ESPI_DEFINITION, PERCENTAGE`. Months run from January 2019 to December 2025.
The data is provisional.
