# Published figures used as cross-checks

`health_target_fsa.csv` holds Health NZ's published "shorter wait times for
first specialist assessment" health target results: the percentage of patients
waiting at the end of the period who had waited less than four months. This
should equal 100% minus the ESPI 2 share of the list for the same month and
area. The June 2025 national figure (62.0%) matches the OIA data
(62.0% to 62.1%).

The values were transcribed by hand from screenshots of the Health NZ health
targets Power BI dashboard (Q4 2025/26, April to June 2026), taken on
4 October 2026. They assume the quarterly result is the end-of-quarter (June)
snapshot, as the dashboard's description says ("patients waiting at the end of
the period"). Check the transcription against the dashboard's own data
download when possible.

The pipeline compares these figures with the ESPI data whenever both cover the
same month (check: "Matches published FSA health target results").
